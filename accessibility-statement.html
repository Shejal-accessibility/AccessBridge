Accessibility Statement

This website aims to conform to WCAG 2.2 Level AA accessibility requirements.

The website supports keyboard accessibility, semantic HTML structure, visible focus indication, screen reader compatibility, and accessible form validation practices.

Accessibility features include:

  • Keyboard accessible navigation
  • Visible keyboard focus indicators
  • Semantic headings and landmarks
  • Accessible forms and validation
  • Consistent navigation mechanisms
  • Skip links for keyboard users

If you encounter accessibility barriers while using this website, please contact the support team through the contact page.
