IssueWCAGConformanceDescriptionIncorrect CodeCorrect CodeRecommendation
Missing explicit form label association1.3.1AOn the enrollment and request forms, form input fields are not properly associated with visible labels. Screen reader users may hear an unlabeled edit field, and speech input users may be unable to target the control by label name.<label>Business Email</label> <input id="email" type="email"><label for="email">Business Email</label> <input id="email" type="email">Ensure every form control has a visible text label and explicitly associate the label using the for attribute that matches the unique id of the corresponding form control.
Status message not announced to assistive technology4.1.3AAOn form submission workflows, dynamic success or validation status messages are updated visually without reliable assistive technology announcement. Screen reader users may not know whether submission succeeded or failed.<div>Form submitted successfully.</div><div role="status">Form submitted successfully.</div>Expose dynamically updated informational messages using role="status" or aria-live="polite" so screen readers announce content changes without requiring manual navigation.
